# 発表スライド

`index.html` をブラウザで開くだけ。ビルド不要。

## 操作

| 操作 | キー |
|---|---|
| 次へ | `→` `Space` `PageDown` `n` |
| 前へ | `←` `PageUp` `p` |
| 最初 / 最後 | `Home` / `End` |

画面の左3分の1をクリックで前へ、それ以外で次へ（タブレットでの発表用）。
URL の `#9` で9枚目から開ける。

## 発表するとき

1. ブラウザで `docs/slides/index.html` を開く
2. `F11`（Mac は `⌃⌘F`）で全画面にする
3. デモを見せるときは別タブに https://signboard.emaker.dev を開いておく

## 構成

| 枚 | 内容 |
|---|---|
| 1 | 表紙 |
| 2-3 | きっかけ・できたもの |
| 4-6 | 使い方（住人向け） |
| 7-10 | 中身・技術選定・仕組み |
| 11-15 | AI との開発プロセス |
| 16 | まとめ |

前半が非エンジニアにも分かる話、後半が技術寄り。
途中で離脱されても要点が伝わる順序にしてある。

## 直したいとき

`index.html` 1ファイルだけ。`<section class="slide">` が1枚に対応する。
掲示板の画面写真は `board.png`（本番から撮ったもの）。
