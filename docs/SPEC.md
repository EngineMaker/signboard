# SPEC: シェアハウス電光掲示板

> ステータス: **ドラフト（フェーズ1 ヒアリング中）**
> 最終更新: 2026-09-20

## 1. 目的

シェアハウスのリビングに常設した iPad に、お知らせを電光掲示板のように横スクロールで表示する。
内容はリモート（Discord / Web管理画面）から更新でき、iPad 本体を操作する必要がない。

## 2. 確定した要件

### 2.1 投稿・編集の権限

- 権限の源泉は **シェアハウスの Discord サーバーの「EM住民」ロール**
- ロール保有者は誰でも: 投稿 / 編集 / 削除 / 現在の表示内容の確認 ができる
- インターフェースは **Discord Bot と Web管理画面の両方**を提供する
  - Bot: スラッシュコマンドで投稿・一覧（日常利用）
  - Web: 一覧・編集・設定変更（Discord OAuth2 でログイン、ロールを検証）
- **API を提供する**（住人が自分でスクリプトから叩けるように）
  - 認証は **個別発行の API キー（Bearer トークン）**
  - Web管理画面から自分のキーを発行・失効できる

### 2.2 お知らせの寿命

- 期限は任意指定、**未指定時のデフォルトは 24 時間**
- 期限切れは表示から自動的に消える（データは残す = 論理削除）
- お知らせが 0 件のときに流す **フォールバックテキスト**を設定できる
  - 例: 「お知らせ募集中」

### 2.3 表示（掲示板画面）

- 複数件の横スクロールローテーション
- 時計・日付の常時表示
- 外部情報（天気・ゴミ出し）は **MVP には含めない**。後のステップで追加できる設計にしておく
- 優先度・色分けは **不要**。全お知らせを同じ扱いで、順番に流す
- 見た目: **シンプルな黒背景＋大きな白文字**（CSS変数でテーマ化し、後から LED ドット風を追加可能に）
- 表示調整（スクロール速度・文字サイズ・テーマ）は **Web管理画面から変更でき、iPad に反映される**

### 2.4 オフライン時の挙動

- 最後に取得した内容を**流し続ける**
- 画面の隅に**小さく警告を表示**する（例: 最終更新 ○分前 / オフライン）
- キャッシュは端末側（localStorage 等）に保持し、再起動しても直前の内容を出せること

### 2.5 表示端末

- **iPad Pro 9.7インチ (MLYJ2J/A)**, **iPadOS 16.7.16**
- 画面 2048x1536 (9.7"), Safari 16 系
- 制約: これ以上 OS を上げられない世代。`:has()` など Safari 17+ の機能は不可。
  A9X / メモリ2GB のため、長時間の常時表示に耐える軽量な描画にする（重い JS アニメーションは避け、CSS transform ベース）
- 利用形態: Safari の「ホーム画面に追加」で全画面（standalone）表示、常時起動

### 2.6 ホスティング・コスト

- ドメイン: **emaker.dev のサブドメイン**を使う
- **ハウス内 Ubuntu サーバーを優先**し、可能なら全部そこに載せる（調査 TBD-2）
- 予算上限: **月額 1,000円程度まで**
- 補足: 定期実行に GitHub Actions を使っていたが起動時刻が不安定で不便だった経験あり。
  本件で定期実行が必要になる場合は、時刻が正確なスケジューラ（ハウス内サーバーの cron / systemd timer 等）を優先する
